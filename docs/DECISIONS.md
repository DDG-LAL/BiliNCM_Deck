# 关键决策

## D1. 基于上游源码 fork，而不是包装原版 exe

原因：

- 原版 exe 是单文件发布，无法安全合并内部逻辑
- 上游源码公开、规模可控（约 22 个 C# 文件、4,500 行）
- 只有 fork 才能真正做到单进程、单状态、单入口
- 上游最后提交 2026-05-11，版本 1.0.1，近期基本停更

## D2. 与上游更新分离

- 不保留指向 `Enkianssus/BiliNCM-Bot` 的自动更新源
- 不自动跟随上游 release
- 需要时手动 cherry-pick
- 本项目自行版本化和发布

边界：

- 脱离上游代码/发布：是
- 脱离 B站/网易云接口：否，仍需维护

## D3. .NET 10 / win-x64

- 上游目标框架为 `net10.0-windows`
- 使用本地 .NET 10 SDK 构建，不改系统 .NET 5
- 最终发布为 self-contained single-file win-x64

## D4. 一个端口 5566

- OBS 只填 `http://127.0.0.1:5566/`
- 设置页 `http://127.0.0.1:5566/settings`
- 原 5555 的所有 API 已迁移到 5566
- 5555 不再监听，也不再有旧网页入口
- 不再需要 PowerShell 关闭 5555 窗口

## D5. 队列语义以旧 Companion 为准

- 当前歌曲不打断
- 网易云播放列表为最终顺序
- 手动拖拽/删除优先
- 重复点歌合并
- 强制插队/强制播放已删除；切歌仅主播和房管可用
- 这些规则直接进入 C# `CompanionQueueEngine`，不再保留伴随进程

## D6. 旧项目不原地改造

- 当前 `BiliNCM_Companion` 保持可用
- 新项目 `BiliNCM-Deck` 独立 git 仓库
- 新项目稳定后再决定是否替换便携版

## D7. 许可与归属

- 保留上游 MIT 声明、项目来源和 NOTICE
- 新项目以 BiliNCM Deck 名义发布
- 不暗示与 B站/网易云官方有关

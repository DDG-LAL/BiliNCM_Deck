# BiliNCM Deck v1.1.0

新增歌词浮层，并保持点歌、队列和权限逻辑不变。

## 新增

- OBS 歌词源：`http://127.0.0.1:5566/lyrics`
- 显示行数支持 1 / 3 / 5 / 7 行，默认 5 行，当前歌词居中高亮
- 复用现有 6 套浮层皮肤，新增“纯歌词”全透明皮肤，字体颜色可调
- 歌词翻译可选，每行原文下方显示小字翻译
- 网易云时间轴歌词精确滚动
- 无时间轴歌词：优先尝试 LRCLIB 外部同步源，失败后按歌曲时长估算
- 设置页可开启“强制静态显示”，关闭滚动，作为手动回退
- 播放位置跟随网易云实际状态，前端只在采样之间平滑插值

## 设置

在 `http://127.0.0.1:5566/settings` 的「歌词浮层」区域调整：

- 显示行数
- 皮肤
- 翻译开关
- 强制静态显示
- 纯歌词字体颜色

配置保存在程序目录 `lyrics-config.json`。

## 已知限制

- 网易云没有歌词时显示「暂无歌词」。
- 无时间轴歌词的外部同步源可能匹配到错误版本；匹配失败或效果不佳时可开启静态显示。
- 歌词同步依赖网易云当前播放状态；暂停、拖动进度后以网易云下一次状态采样为准。
- 网易云音乐只支持 2.10.13；3.x 不兼容，其他 2.x 版本未验证。

## 升级

覆盖旧版程序即可，配置和日志会保留。重启 Deck 仍会清空浮层待播列表，NCM 中已存在的待播副本不会自动恢复跟踪。

# Phase 2/3 回归状态（v1.1.0）

> 完整用例仍以 `REGRESSION.md` 为准。本文件记录 v1.1.0 发布时的已知状态。

## 已通过核心回归

- 同时点不同歌：两条弹幕都落盘并各自入队
- A/B 同歌撤回隔离：最后一条请求消失才删除 NCM 副本
- `置顶` / `置顶点歌`：当前歌不变，目标位于当前歌下一首；连续置顶以最后一次排最前
- 普通观众权限：不能置顶、切歌、关闭点歌、移除或撤回他人请求
- 主播切歌、移除、暂停/恢复
- `live_status`：初始读取、WS LIVE/PREPARING、60 秒轮询
- `danmaku.log` 全量弹幕落盘
- NCM CDP 短暂不可用后恢复
- 歌词浮层：网易云时间轴歌词、翻译、LRC 解析、LRCLIB 外部同步源、时长估算、1/3/5/7 行、7 套皮肤、静态回退均已本地验证

## 已知限制

- 重启 Deck 会清空浮层待播列表；NCM 中已存在的待播副本不会自动恢复跟踪。
- `置顶` / `优先` 只匹配歌名或点歌人昵称，不匹配歌手名。
- 房管功能已实现，但发布前未使用真实房管账号完整复测。
- 无时间轴歌词的外部同步源可能匹配错误版本；可按需开启静态回退。
- 歌词暂停/拖动进度的实际对齐仍需在真实网易云播放中复核。

## 后续建议

- 在真实房管账号下复核权限矩阵
- 如需重启连续性，增加待播队列持久化或启动时收养 NCM pending d
- 如继续使用 `置顶 歌手名`，考虑增加 `ArtistName` 匹配

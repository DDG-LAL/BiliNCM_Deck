# BiliNCM Deck v1.1.2

修复 v1.1.0 / v1.1.1 的歌词同步问题，并完成托盘、设置页和歌词皮肤的界面微调。

## 歌词同步修复

- 播放位置改用网易云原生进度 `cefPlayer.w6`，不再使用拖动/跳转后会滞后的 `playedTime`
- 拖动网易云进度条后，歌词浮层会自动吸附到对应行，不再停留在旧位置
- 暂停时拖动、恢复播放后继续保持对齐
- 监听网易云原生 `seeked` 事件，使用 seek 目标位置处理暂停状态下的跳转
- 读取网易云当前歌曲的 `lrc.offset`，点击 +0.5s / -0.5s 后歌词浮层同步偏移
- 多个页面/OBS 同时打开时，seek 和偏移信号不会只被其中一个页面消费
- 歌词翻译默认开启；旧配置会一次性迁移为开启，之后手动关闭会保持

## 性能与界面

- 移除歌词浮层背景模糊，降低浏览器和 OBS 的 GPU 压力
- 缓存布局参数，只在歌词行变化时更新 `transform`，使用 `translate3d`
- 暂停时停止无意义的逐帧更新
- 托盘菜单改为：点歌浮层、歌词浮层、设置、日志、检查更新、退出
- 设置页栏目顺序调整为：直播登录、点歌队列皮肤、自定义背景、适配方式、画面调整、歌词浮层、关于 / 更新
- 自定义背景、适配方式、画面调整增加“仅用于点歌队列浮层”的说明
- 点歌队列皮肤「透明歌词」更名为「透明无色」
- 歌词浮层移除「透明歌词」皮肤，保留 5 套队列皮肤 + 「纯歌词」，旧配置自动回退到「纯歌词」
- 设置页按钮统一为「点歌浮层」「歌词浮层」
- 缩短直播登录和歌词浮层的说明文字

## 从 1.0.0 升级

1. 到 Releases 下载 `BiliNCM-Deck-Updater.exe`
2. 放到 `BiliNCM-Deck.exe` 同目录
3. 建议先下播，然后退出 Deck
4. 双击 Updater，按提示更新
5. 完成后自动重启

Updater 会校验 SHA256、备份旧版本；失败时自动回滚。登录、配置、背景、歌词设置和日志都会保留。

## 从 1.1.x 升级

设置页 →「关于 / 更新」→「检查更新」→「下载并更新」；也可以右键托盘图标 →「检查更新」。

- 更新会关闭整个 Deck，待播列表会清空，建议下播后再更新
- 更新失败自动回滚，当前版本不受影响
- GitHub 无法访问时可打开发布页手动下载

## 注意事项

- 网易云音乐只支持 2.10.13；3.x 不兼容，其他 2.x 版本未验证
- 更新后建议在 OBS 中刷新歌词浏览器源缓存，或删除后重新添加 `http://127.0.0.1:5566/lyrics`
- 歌词偏移读取的是网易云当前歌曲缓存的 `lrc.offset`；如果使用特殊歌词源仍不同步，可开启「强制静态显示」作为回退
- 未签名程序可能触发 Windows SmartScreen 提示

# BiliNCM Deck v1.0.0

首个公开版本。

## 主要功能

- 单进程、单便携包，只监听 `127.0.0.1:5566`
- 完整 Companion 队列状态机：FIFO、重复合并、已播升级、NCM 重启恢复
- `置顶` / `置顶点歌`：放到当前歌下一首，连续置顶以最后一次排最前
- B站 Brotli 批量包解析：同一包内多条弹幕不再丢失
- 重复点歌撤回隔离：最后一条请求消失时才删除 NCM 副本
- `live_status`：初始读取 + WS `LIVE`/`PREPARING` + 60 秒低频轮询
- `deck.log` 与 `danmaku.log`：独立轮转，敏感字段脱敏
- OBS 浮层、设置页、托盘图标、配置迁移、背景图处理

## 运行要求

- Windows 10/11 x64
- 网易云音乐 2.10.13，调试端口 `9222`
- B站主播账号扫码登录
- 便携包已自包含 .NET 运行时

## 已知限制

- 重启 Deck 会清空浮层待播列表；NCM 中已存在的待播副本不会自动恢复跟踪。重启前请确认，或重新点歌。
- `置顶` / `优先` 只按歌名或点歌人昵称匹配，不匹配歌手名。
- 房管功能已实现，但仍建议在真实房管账号下复核。
- 不提供自动更新、强制插播或强制播放。

## 升级说明

从旧版便携包迁移时，把 Deck 放到同一目录可自动读取旧 `current\config.json`；独立目录可使用 `--legacy-root`。旧日志和 `overlay-state.json` 不会迁移。
